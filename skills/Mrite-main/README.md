# 数学建模竞赛 Skill + 论文模板 + 算法库

> 长期维护的数学建模竞赛一站式仓库，集成自动求解 Skill、论文模板、App 版本与常用算法。

---

## 仓库结构

```
.
├── Skill/          # Claude Code Skill：读题→求解→论文→编译 全流程自动化
├── App/            # App 版本（独立应用，待开发）
├── 模板/           # 论文 LaTeX 模板源头（format.cls + 空白 tex + 字体）
└── 算法/           # 常用数学建模算法库（按类型分类）
```

## 各模块说明

### Skill/
基于 Claude Code 的数学建模竞赛自动求解技能。放入赛题和数据后，说"开始求解"即可全自动完成：读取输入 → 制定计划 → 逐题求解 → 撰写论文 → 编译 PDF。

详见 [Skill/README.md](Skill/README.md) 和 [Skill/CLAUDE.md](Skill/CLAUDE.md)。

### App/
独立的 App 版本（待开发），将 Skill 能力封装为可视化应用。

### 模板/
论文 LaTeX 模板的**唯一源头**。包含 `format.cls` 样式文件、思源宋体字体、14 个章节空白 tex 模板。`Skill/论文/` 中的模板文件由本目录复制而来，修改模板请在此处进行。

详见 [模板/README.md](模板/README.md)。

### 算法/
常用数学建模算法代码库，按问题类型分类：优化、预测、分类、评价。

详见 [算法/README.md](算法/README.md)。

---

## 使用方式

### 使用 Skill 自动求解
1. 将赛题放入 `Skill/题目/`
2. 将数据放入 `Skill/数据/`
3. 在 Claude Code 中说"开始求解"

### 单独使用论文模板
1. 复制 `模板/` 下所有文件到工作目录
2. 编辑各 tex 文件填写内容
3. `xelatex 论文.tex` 编译

---

## 维护约定

- **论文模板**：`模板/` 为源头，修改后同步至 `Skill/论文/`
- **编译产物**：`.aux` `.log` `.pdf` 等已通过 `.gitignore` 忽略
- **命名规范**：代码、图、CSV、tex 文件一律中文命名
