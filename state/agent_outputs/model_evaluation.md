# 模型评价与推广

> 本文件所有数值均可追溯至 `results/q{i}_results.json` 与 `state/agent_outputs/sensitivity_report.json`，文中以方括号标注来源。

## 一、模型的优点

### 1.1 机理-代理联合建模的"解释性 + 精确性"分工

采用**流向分段热-流耦合机理模型（Q1）**与**高斯过程回归代理模型（Q2）**双层架构，二者定位互补：

- **机理模型负责解释规律**：在标定系数 κ 后，3 个设计变量对 3 个指标的**影响方向 9 项全部正确**，并成功再现全部非单调现象——R 随 r 呈 U 型谷值（r≈0.2）、T 随 n 呈 U 型谷值（n=4）、P 随 h 近似按 1/h² 下降，以及 R-P 强负相关（corr=-0.684）这一"强化换热必增流动代价"的物理权衡 [`q1_results.json` influence_trends / rationale]。
- **代理模型负责精确映射**：GPR 5 折交叉验证 R²=0.9981/0.9988/0.9941，LOOCV R²=0.9986/0.9991/0.9966，RMSE 最低达 0.0004 [`q2_results.json` gpr_loocv]，为 Q3-Q5 的优化与稳健性分析提供优化级精度。
- **量化分工收益**：在 P 指标上，机理模型 R²=0.779、GPR LOOCV R²=0.9991，代理较机理提升约 0.22；而 GPR 给出的光滑 Pareto 前沿与 σ²(x) 方差输出又是机理模型无法提供的。二者不是替代关系，而是"机理定方向、代理定精度"的互补链。

### 1.2 GPR 高精度与不确定度量化的创新

- 在仅 84 样本的小数据下，Matern 5/2 核 + ARD 各维独立长度尺度 + WhiteKernel 的 GPR 达到 LOOCV R²≥0.9966，且 ARD 自动特征选择输出各指标的特征重要度（如 R 指标三变量重要度 0.327/0.336/0.337 均衡，P 指标 r/h/n 为 0.384/0.227/0.389），与机理结论互相印证 [`q2_results.json` kernel_hyperparams]。
- **核心增值点在于 σ²(x) 认知不确定度输出**：多项式（R 指标 R²=1.0，实为插值）与随机森林（R² 仅 0.65~0.82）均无法提供逐点预测方差。正是这一输出，使 Q5 能够实现"参数偶然不确定度 + 模型认知不确定度 + 工况波动"的双源三源传播闭环，形成证据链 `论文结论 → 代理 → 数据` 的完整追溯 [`q2_04_gpr_uncertainty.png`]。

### 1.3 Max-Min 鲁棒优化的顶点闭式约简（可解性贡献）

- 权重域 Max-Min 鲁棒问题本为**双层优化** `max_{w∈Δ₃} min_x S(x,w)`，直接求解需在每次权重采样下嵌套求解内层优化，计算代价极高甚至不可解。
- 利用 `S(x,w)` 对 w 线性、单纯形 Δ₃ 的顶点恰为三个纯权重这一凸性结构，**闭式约简为单层 minimax**：`x* = argmin max{R̃,P̃,T̃}` [`q4_results.json` vertex_reduction]，从而用标准进化算法（DE，多 seed）一次性求得严格鲁棒解。
- 全域鲁棒方案 (r*=0.2364, h*=4.5, n*=6) 的最坏情形分 W=0.2380 与偏好敏感带宽 B=0.0590 **在三个候选方案中均为最小**（熵权 TOPSIS 方案 W=0.2546/B=0.1021，等权重标量化方案 W=0.3748/B=0.3748），均匀期望 E_S=0.2033 仅略逊于 TOPSIS 方案 [`q4_results.json` wbe_table / scheme_comparison]，说明鲁棒代价有限。

### 1.4 三方案交叉验证设计

- 熵权 TOPSIS（r*=0.2148, h*=4.5, n*=6）、等权重标量化（r*=0.2169, h*=4.5, n*=4）、全域 Max-Min 鲁棒（r*=0.2364, h*=4.5, n*=6）三个独立求解路线，**r、h 高度一致（r≈0.215~0.236，h 均取可行域上界 4.5）**，仅 n 在 {4,6} 间分歧，归一化设计距离=0.2001<0.3，判定为"基本一致" [`q3_results.json` consistency_check]。
- 优化前沿含 442 个非支配点，支配 84 个数据设计中的 82 个（97.62%），综合最优方案较数据最优设计（等权重标量化口径）提升 1.12% [`q3_results.json` data_dominance_check]。
- 三种方案交叉印证，排除单一优化器或单一判据带来的偶然性。

### 1.5 双源不确定度传播的严谨性

- Q5 将指标总方差按来源分解为**参数偶然不确定度 / 模型认知不确定度 / 工况波动**三类，和≈1：R 由工况波动主导（92%）、P 由加工误差主导（93%）、T 由工况波动主导（69%）[`q5_results.json` variance_contribution]。
- 同时给出概率化稳定性评估（P10/P50/P90、CV、失效概率）与多视角灵敏度（局部弹性 ±1%、Sobol 全局、有限扰动 ±20%），三视角结论互相印证，而非单一偏导的近似 [`q5_01~04`]。

## 二、模型的缺点

### 2.1 Q1 机理模型对 R、T 拟合较弱

- 机理模型在 P 指标上拟合较好（Pearson=0.882、R²=0.779），但 **R 与 T 的 R² 仅 0.306 与 0.212** [`q1_results.json` fit_metrics]。
- 量化后果：机理模型残差标准差约为数据标准差的 **2.2~2.5 倍**（R≈2.5、T≈2.2，对应残差方差约为数据方差的 5~6 倍，按 `q1_results.json` rmse 与 84 样本数据标准差计算），即模型残余波动显著大于数据本身波动。
- 结构性权衡：T 的 U 型峰谷差本身仅约 0.05~0.08（无量纲），为使 T 的非单调形态得以显现，需放大 Tj,max 的移动幅度，这一参数化方式会放大 R 的散布——机理模型在 R 与 T 之间难以两全。故机理模型定位为**规律与先验解释**，不作为精确求解依据（此缺点的缓解依赖 GPR，见 1.1）。

### 2.2 训练域受限与边界依赖

- 代理训练数据仅 84 样本，覆盖 r∈{0,0.1,0.15,0.2,0.3}×h∈{3,3.5,4,4.5}×n∈{0,2,4,6,8,10}，**训练域外（如 n∈(0,2)、h>4.5）无数据支撑**，GPR 外推不可靠（假设 A13）。
- 三个最优方案 h* 均落在可行域**上边界 4.5** 上，本报告 Phase 6 的 h 正扰动被边界截断（h+10% 与 h+20% 等效），意味着"在可行域内无进一步降 P 空间"的同时，也提示**最优解贴近设计边界、对域外未知存在依赖** [`sensitivity_report.json` 扰动表 / `q5_results.json` warnings]。

### 2.3 阈值与噪声量级的主观性、n 约束的非物理性

- Q5 的失效阈值（名义值 ×（1+5%））与工况波动量级（σ_op=1.5%，取自 1~2% 经验区间，假设 A10）均为**人为设定**，换用其他阈值/量级会改变失效概率绝对值（尽管 R/T 高度稳定、P 基本稳定的相对结论不敏感）。
- n 仅取偶数 {0,2,4,6,8,10}、r=0⟺n=0 的耦合约束**源于数据采样规则而非物理必然**，若真实加工允许奇数排或 n∈(0,2)，当前优化结论（n*∈{4,6}）需重新审视。

## 三、与淘汰候选模型的量化对比

| 对比维度 | 采用模型 | 淘汰/对照模型 | 量化证据与理由 |
|---------|---------|-------------|---------------|
| Q1 机理建模 | 流向分段热-流耦合模型（20 段递推） | 集总电阻网络 | 集总网络**无流向分辨率，无法输出温度非均匀性 T，无法解释 T-n U 型**；分段模型可同时解释 R/P/T 及全部非单调现象（R-r U 型、T-n U 型、R-P 权衡），且结构可标定 [`model_design.json` elimination_rationale] |
| Q2 代理精度 | GPR（Matern5/2 ARD+WhiteKernel） | 多项式回归 / 随机森林 | GPR LOOCV R²=0.9986/0.9991/0.9966；多项式 5 折 CV R²=1.0/0.9995/0.9997（R 指标 R²=1.0 实为 84 样本上的插值过拟合，**且无 σ²(x) 输出**）；RF R² 仅 0.7588/0.8152/0.648，较 GPR 低 0.18~0.35 [`q2_results.json`] |
| Q3 多目标决策 | NSGA-II + 熵权 TOPSIS | 单权重标量化 | 前沿 442 点、支配 97.62% 数据设计，提供全偏好空间可选方案；标量化仅给单点，本项目中作为交叉验证（r/h 与 TOPSIS 一致）而非主模型 |
| Q4 鲁棒优化 | Max-Min + 顶点闭式约简 | 无约简双层优化 | 双层 max-w min-x 需嵌套求解，计算不可行；顶点约简将其化为单层 minimax 后可用 DE 求解；全域鲁棒解 W=0.2380、B=0.0590 均为三方案最小 [`q4_results.json` vertex_reduction] |
| Q5 稳健性评估 | 双源蒙特卡洛（N=20000） | 3×3 局部弹性矩阵 | 局部弹性仅给出确定性偏导；MC 给出概率化 CV、P10/P50/P90、失效概率与方差来源分解，并叠加 Sobol 全局灵敏度（自实现直接 MC 条件方差估计，规避 SALib 在 R 指标微小方差域的估计抖动）补充交互效应 |

**分工互补的量化结论**：机理模型以"方向全对、P 规律强（Pearson=0.882）"承担解释性，GPR 以"LOOCV R²≥0.9966 + σ²(x)"承担精确性；多项式在 84 样本上近似插值且无不确定度，随机森林精度与平滑性双不足——故 GPR 是唯一同时满足"防过拟合 + 不确定度量化"的代理选择 [`q2_03_model_compare.png`、`s6_verifier_04_model_compare.png`]。

## 四、改进方向

1. **扩充训练域**：以真实 3D CFD 生成更多样本，重点补齐 n∈(0,2) 与 h>4.5 的空白，使鲁棒最优解脱离设计域边界；并采用**自适应采样（贝叶斯优化/BayesOpt 式主动选点）**，在 GPR 预测方差 σ²(x) 最大的区域优先补样，用最少 CFD 次数最大化信息增益。
2. **物理信息嵌入（Physics-informed GPR）**：将 Q1 机理模型作为 GPR 的均值函数、用 GPR 拟合机理残差（即 model_design 中的 Q2_C4 备选方案），可同时保留外推合理性与局部精度，缓解 2.2 的训练域依赖。
3. **真实 3D CFD 验证**：机理模型的歧管并联假设与 T 的 U 型物理机制需用三维流场（含二次流、入口段效应）复核，确认"T 受 n 主导（Sobol S1=0.56）"这一结论在三维情形下的稳健性。
4. **工况显式建模**：将流量、入口温度作为代理显式输入重训（替代 Q5 的解析修正与 σ_op=1.5% 假设），直接量化工况对 R/P/T 的影响，消除阈值与噪声量级的主观性。
5. **流固热耦合扩展**：将固体导热与流体对流的双向耦合纳入机理分段模型，细化 n 对温度均匀性的作用路径，提升 T 指标的机理拟合度（R² 从 0.212 起步）。

## 五、推广条件

- 本"**机理定方向 + 代理定精度**"混合框架适用于一般"参数→性能映射 + 多目标优化 + 鲁棒设计"的工程优化问题（热管理、结构轻量化、工艺参数优化等），前提是设计变量可枚举/连续、目标函数可数值求值。
- **顶点闭式约简**可直接推广到任何"目标函数对权重仿射线性、权重域为凸多胞形"的 Max-Min 决策问题；当目标对权重非线性时，退化为顶点/网格采样的近似求解。
- **双源不确定度传播**要求所选代理具备认知不确定度输出（GPR 或其他贝叶斯代理），否则只能传播参数偶然不确定度；该前提是本框架向其他问题推广时的最低要求。
