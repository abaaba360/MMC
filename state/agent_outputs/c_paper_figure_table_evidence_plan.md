# C题论文图表证据计划

本计划以“结论—所需证据—载体—图后落点”为唯一取舍标准，数据均来自已经验证的结果文件；绘图阶段不重新求解模型。

| 问题一 | 储能在低价或光伏富余时充电，在高价且净负荷较高时放电，并始终满足 SOC 边界 | 典型日三联图 | MATLAB 重绘并替换 | 充放电时段、购电削峰、SOC 上下界、首末状态 |
| 问题一 | LP 与 MILP 在本数据上同值，且相较无储能显著降费 | 对照三线表 | 保留并规范 | 目标值、节省额、节省率、互斥是否自然满足 |

## 删除或不新增的图

- 不新增装饰性流程图、模型名词关系图、重复年度汇总图。
- 不把逐时精确购电量全部画成密集曲线；指定时点继续用表格回答。
- 不增加无法从现有结果文件复算、只靠示意或生成式图像表达的“证据图”。
