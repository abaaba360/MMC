# 2026 C题第一版论文结构与版式蓝图

## 一、结论先行

本题第一版论文应采用“统一物理骨架、四问逐层增加信息结构”的主线，而不写成四个互不相关的算法报告。正文建议控制在 **24—27页**，为最终增补、排版波动和AI工具使用声明预留3页以上安全余量；摘要另占电子论文第一页。模型名称只能出现在题干事实、数学对象和约束已经推导清楚之后。图表应围绕“能源从哪里来、储能怎样跨时段转移、计划怎样被更新、费用怎样形成、策略怎样验证”组织，避免装饰性流程图和算法名堆砌。

本蓝图只总结所给材料的结构规律，不复制优秀论文表述。规则采用以下优先级：2026全国现行要求，其次北京赛区通知和赛前会议说明，再次标准Word模板，最后才是历届优秀论文的经验做法。

## 二、已核对材料及可借鉴边界

### 2.1 2026硬性边界

从2026参赛规则、章程、北京赛区通知和赛前会议材料中，应锁定以下要求：

1. 电子论文第一页为摘要专用页，只放题目、摘要和关键词，无需英文翻译，原则上不超过一页。
2. 论文不设目录。正文不超过30页；这里的正文包括正文主体、AI工具使用声明和参考文献，不包括摘要专用页和其后的附录。
3. AI工具使用声明必须位于参考文献之前，并使用当年规定文本。使用AI时，支撑材料必须含准确命名的 `AI工具使用详情.pdf`。
4. 附录至少包括支撑材料文件列表和全部完整、可运行的源程序；源程序还须同时放入支撑材料。
5. 论文与支撑材料均须匿名，身份信息不能出现在正文、附录、代码、文件名、文件属性和注释中。
6. 竞赛章程把假设合理性、建模创造性、结果正确性和文字表述清晰度列为主要评奖标准。因此，论文的核心不是模型名称，而是从题目事实到模型、从模型到结果、从结果到原问题结论的可核验链条。
7. 2026赛前评阅意见特别提醒：参考文献不得虚构或一味堆积英文文献；整体框架图可以有，但要自行按真实逻辑绘制；图、表必须解释；不要在论文结尾机械地逐问复述；不必为每个子模型重复写优缺点。

### 2.3 C023、C132及其他优秀论文的有效经验

两篇C题论文都表现出以下值得保留的结构规律：

- 摘要不是问题复述，而是按问题顺序给出“为什么这样建模、用了什么求解结构、得到了什么定量结论、如何验证”。C023正文第一页约一页完成四问闭环；C132的信息密度更高，每一问都同时出现方法与量化表现。
- 问题分析承担从现实语言到数学模型的桥梁作用。优秀论文先说明数据结构、物理机制、决策变量和难点，随后才给出模型名称。
- 总体框架图只画一次，用于说明四问递进关系；每问是否另画流程图取决于其内部步骤是否确实复杂。
- 模型建立页以“文字解释—公式—变量说明—下一步推导”交替展开，公式不孤立成墙。关键参数表会说明设计依据，而不是只给数值。
- 结果通常采用“图或表＋紧邻的解释段”。解释段至少回答趋势、机制、约束是否满足以及该结果如何回应原问题。
- 正文结束后进入参考文献、AI说明或使用记录、附录代码。C023正文约24页、总文件45页，密度更适合作为2026写作参照；C132的参考文献出现在约第40页，超过2026现行30页正文上限，因此只能借鉴论证展开，不能借鉴页数。

需要舍弃的历史习惯包括：旧论文的AI记录位置和表述、把AI工具直接列入参考文献的旧口径、过长符号表、每问都画相同形状的流程图、在结尾逐问重复摘要，以及将整页代码截图当成正文内容。

## 三、适合本C题的章节结构

### 摘要专用页

题目建议突出研究对象和递进机制，例如“基于跨时段储能状态与滚动决策的微网购电调控研究”。标题不应把MILP、MPC、两阶段优化等名词全部塞进去。

摘要正文建议按六个自然段组织：第一段用2—3句交代微网供需、光伏不确定性、储能跨时段调节和购电结算的核心矛盾；第二至第五段分别对应四问；最后一段概括统一性、可执行性和验证结果。每问段落必须包含“题目新增了什么条件—该条件怎样转化为数学结构—采用何种求解方式—最重要的2—3个数值结果—怎样确认可信”。初稿可先写约750—950个汉字，再依据最终单页渲染压缩，不能用固定字数替代版面检查。

摘要中每问至少保留一组可直接回答题目的数字。可优先安排：问题一的最小费用、购电量、光伏消纳率和LP下界差距；问题二的全年费用、紧急购电量或占比；问题三的调整后成本、紧急购电下降幅度和调整次数；问题四的因果策略成本、完全价格信息下界和信息价值差距。摘要不放文献、流程图、长公式或未经结果文件确认的数字。

关键词建议从下列方向中选4—6个：微网调度、储能状态转移、混合整数线性规划、两阶段随机优化、滚动时域优化、因果价格预测。只有正文真正保留的模型才能进入关键词。

### 一、问题重述（0.5—0.8页）

用自己的语言交代微网、光伏、储能、负荷和外网之间的能量关系，再按四问说明决策时点、可用信息、结算规则和输出任务。不要照抄题面数据表，不在此处提前写求解结果。四问应被写成递进关系：确定性典型日基线，加入实际偏差与紧急购电，加入日内预测更新与非对称调整，再加入实时电价和信息可得性。

### 二、问题分析（1.2—1.6页）

设置2.1至2.4分别分析四问，再用一张总体路线图收束。每节都采用“题干事实—造成的数学难点—需要新增的状态或约束—与前一问的关系”的写法，不在本节大段罗列最终公式。

总体路线图建议沿一条主轴画出：能量守恒与储能状态 → 确定性日前基线 → 实际偏差和紧急追索 → 6小时滚动更新与逐次结算 → 实时价格下的因果决策与完全信息下界。图中不得出现工作流文件名、Agent名称或算法名墙。

### 三、模型假设（0.5—0.8页）

只写无法从题目直接得到、但为封闭模型确有必要的假设，并逐条给理由。题目已经明确的储能容量、功率、90%充放电效率、结算倍率等应列为参数或规则，不能伪装成“假设”。本题的合理假设可以围绕时间步内功率恒定、忽略未给出的储能自放电和寿命成本、微网线路损耗未单独计入、允许弃光但需显式核算、预测与实际数据的时间戳对齐方式。任何假设都要说明若不作该假设会缺少什么数据或导致什么变量不可识别。

### 四、符号说明（0.7—1.0页）

使用三线表，按“符号、含义、单位”组织。只列贯穿多问的核心符号，如负荷、可用光伏、光伏实际利用量、购电功率、充放电功率、储能电量、弃光量、紧急购电量、电价和时间步长。问题三的增购、减购和版本索引可在对应小节首次出现时解释，避免把符号表扩成两页。必须明确功率为kW、单时段能量为kWh、费用为元，状态转移式中要显式出现时间步长。

### 五、模型的建立与求解（16—18页，全文核心）

#### 5.1 数据处理与统一物理基础（1.5—2.0页）

先说明10分钟时间网格、日期与时段索引、缺失和异常检查、小时级预测到10分钟网格的映射规则及单位统一。随后从微网母线上的能量守恒推出供需平衡，从储能“本时段充入或放出会改变下一时段电量”推出状态转移，从容量和功率铭牌推出上下界，再解释充放电效率各90%为何分别出现在充电项和放电项的不同位置。统一给出互斥充放电约束及弃光变量的物理含义。

本节要把四问共享的方程一次讲透，后文只说明新增结构，避免每问重复一套能量平衡公式。

#### 5.2 问题一：确定性典型日调度（2.5—3.0页）

写作顺序应为：题面给出完整的负荷、光伏和分时电价，因此每个时段的供需量均为已知；储能电量连接相邻时段，决策不能逐时贪心；费用、购电边界和储能边界为线性，但禁止同时充放电需要一个二元状态变量。由此自然形成以购电费用最小为目标的确定性混合整数线性优化，而不是先抛出“MILP”名称。

随后完整写出决策变量、目标函数、供需平衡、SOC转移、容量和功率约束、充放电互斥、日初日末SOC一致。求解部分只需说明采用能够给出全局最优界的线性整数求解器及终止误差，不把求解器当作模型。结果部分要同时给出调度曲线、费用分解、光伏消纳和约束检查，并用去掉互斥二元变量的LP结果作为连续松弛下界。

#### 5.3 问题二：严格日前两阶段决策（3.5—4.0页）

先从题意解释为什么问题二不等同于问题一：0点制定的购电与储能计划必须在光伏实际值完全实现之前固定，而实际供电不足只能通过5倍紧急购电弥补。这个“先决策、后观察、再补救”的时间顺序直接产生两阶段结构；第二阶段不能偷偷重排储能，否则会越过题目授权边界，也会削弱问题三的递进意义。

正文应清晰区分日前变量和情景实现后的紧急购电变量，说明光伏预测误差情景如何只用决策时点以前的数据构造、情景概率怎样由样本频率获得，并写出一月热启动、跨日SOC连续和二月至年末统计口径。结果布局以全年汇总为主，再用1—2个代表日解释应急购电出现的原因。检验重点是时间切分、防未来数据泄漏、每个情景的供电约束和紧急购电费用回算。

#### 5.4 问题三：滚动修正与逐次结算（4.5—5.5页）

本节先写清信息更新机制：0、6、12、18时获得新的未来光伏预测；已经执行的时段不可回溯；尚未执行时段可以调整；每次调整相对于上一版有效计划逐次结算。以上事实使优化窗口随时间向前移动，实际只执行当前窗口的第一段决策，因而自然形成确定性滚动时域优化。再说明由于每个窗口仍含充放电互斥，它在数学上是MILP型MPC。

减购结算统一按已确认口径书写：在原计划费用已计入时，减购量对应正常费用退回50%，增购量按1.5倍计入，紧急购电按5倍计入；不得再引入附加罚款替代解释。结算公式后应配一个很短的数值例子，防止读者误解正负号。结果应呈现四版有效计划如何演变、每次增减购量、计划费用/调整费用/紧急费用以及最终SOC安全性。

场景MPC和CVaR-MPC不能预先写入主模型。只有其参数全部由滚动样本外数据稳定确定，并在平均总成本、三类费用、紧急购电量、95%成本分位数、最差成本、最低SOC和求解时间等指标上表现出超过不确定性的显著增益时，才以“风险增强”小节保留；否则正文只报告确定性MPC，并把增强尝试从论文主线删除。

#### 5.5 问题四：实时电价下的因果策略（3.5—4.5页）

先指出“附件给出了事后完整电价”和“决策时能够知道的价格”不是一回事。实际在线策略在时刻作决策时只能使用此前价格、当前价格和当时可获得的预测，因此必须满足因果信息约束；相同优化模型若直接输入未来真实价格，则得到的是完全价格信息成本下界，不能称为可执行策略。

本节分别在问题二和问题三框架中替换价格信息：日前版本在0点形成未来价格预测，滚动版本在0、6、12、18时用新增历史更新预测。两者均按时间滚动训练和验证。完全信息下界与因果策略保持物理约束、结算规则和其他输入一致，仅改变价格可见性，这样二者差额才能解释为价格信息价值。`result4-2`和`result4-3`应以因果策略为主结果，完全信息只作对照基准。

### 六、模型检验与结果可信度（2.0—2.8页）

不要机械凑“误差、灵敏度、稳健性”三件套，而应针对本题最容易失败的位置设计检验：

- 物理可行性：逐时供需平衡残差、SOC上下界、充放电功率界、互斥状态和日初日末条件全部检查，报告最大违反量。
- 费用可追溯：从逐时购电量与电价重新回算计划费、调整费和紧急费，汇总值应与优化目标一致。
- 模型基线：问题一报告MILP与LP连续松弛下界差距；问题二可报告确定性计划或无应急风险意识的基线；问题三比较滚动调整前后；问题四比较因果策略与完全信息下界。
- 时间因果性：问题二情景和问题四价格预测的训练集截止日期必须早于决策日，滚动验证不能随机打乱全年时序。
- 参数敏感性：只扰动确实影响结论且有物理意义的参数，例如储能容量、功率、初始SOC或预测误差规模；90%效率是题定值，主结果不改解释，但可在模型局限部分说明现实设备可能偏离。

### 七、模型评价与推广（0.8—1.2页）

按整套模型写优点和不足，不逐问重复。优点必须对应证据，例如统一状态方程保证四问口径一致、严格信息集避免未来泄漏、逐次结算避免重复计费、MILP最优界提高可验证性。缺点可写未计储能寿命成本、线路损耗和电池退化，或价格预测受单年样本限制。推广部分用一段说明如何加入需量电费、储能退化成本、多储能单元或配电网潮流约束。不要在末尾再做一次四问摘要式总结。

### AI工具使用声明、参考文献与附录

AI工具使用声明单独设置在参考文献之前，内容必须与真实台账、代码标注和支撑材料一致。参考文献采用正文按需引用、文末一一对应的方式，数量由真实相关性决定；既要有微网优化、储能调度、随机优化、MPC或电价预测的权威来源，也要保留必要的中文来源，不能为了显得专业而堆满英文条目。

附录首先列支撑材料文件清单和运行说明，再列全部可运行源代码。正文只保留关键伪代码或求解流程，不放整页程序截图。代码应以可复制文本形式排版，且与支撑材料中的源文件一致。

## 四、模型“从题目长出来”的统一写法

每个模型小节开头先写一段推导链，推荐使用以下六句结构，随后才写模型名称：

1. 题目明确给出哪些对象、时点和规则。
2. 这些事实意味着决策之间存在什么联系，为什么不能逐时或逐日独立处理。
3. 因此定义哪些决策变量和状态变量，各自对应现实中的什么量。
4. 题目要求“费用最低”怎样形成目标函数，每一项费用从哪条结算规则来。
5. 设备、供需和信息边界怎样逐条形成约束，哪些约束使模型从连续优化变成整数优化或两阶段优化。
6. 至此模型具有哪种数学结构，所以选择何种求解器；求解器只是利用该结构计算结果。

本C题四问的推荐生长句分别是：

| 问题 | 题干触发点 | 数学结构 | 名称出现时机 |
|---|---|---|---|
| Q1 | 10分钟供需、SOC跨时段、功率/容量边界、充放电互斥 | 线性能量网络＋二元互斥 | 写完目标和约束后称为确定性MILP |
| Q2 | 0点固定计划、实际光伏后实现、仅紧急购电补救 | 先决策后实现的两阶段结构 | 写清一阶段/二阶段变量后称为严格日前两阶段随机MILP |
| Q3 | 四次预测更新、历史不可改、未来可重排、非对称逐次结算 | 移动窗口＋版本递推＋分段线性费用 | 写清窗口、执行和结算后称为MILP-MPC |
| Q4 | 电价实时波动、未来真实价决策时不可见 | 因果信息集＋滚动价格预测 | 写清可见信息后称为因果在线策略；真实未来价只称完全信息下界 |

应避免的写法是：“本文采用MILP、随机规划、MPC、CVaR等先进模型进行求解。”这种句子没有说明这些结构为何必要，也无法让评委判断某个模块是否真实解决了题目中的困难。

### 5.2 视觉与排版规范

- 图形使用统一的色盲友好配色。建议光伏用暖黄、外购电用蓝、储能放电用绿、储能充电用紫或负向面积、负荷用深灰线、紧急购电用红；同一变量在全篇保持同色。
- 图内不重复写大标题，标题由图题承担；坐标轴必须有变量名和单位。时间序列刻度避免拥挤，10分钟数据不应把144个标签全部画出。
- 输出优先使用矢量PDF/SVG；必须使用位图时至少300 dpi。不要使用3D柱图、渐变背景、阴影装饰、彩色表格底纹泛滥或AI插画风流程图。
- 多子图统一标注“(a)(b)”，共享图例和横轴；避免双纵轴造成误读，确需同时呈现SOC与功率时采用上下子图。
- 表格使用三线表，单位写入表头，数值按测量和决策精度统一保留小数位；同一指标在摘要、正文、结果文件中精度一致。
- 图表出现后必须紧接解释段，顺序为“看到什么—为什么会这样—约束是否满足—这回答了题目什么”。不能连续放两三张图而没有文字。

## 六、页数预算与写作优先级

| 部分 | 建议页数 | 主要控制点 |
|---|---:|---|
| 摘要专用页 | 1页（正文页数外） | 必须单页渲染通过 |
| 一、问题重述 | 0.5—0.8 | 不抄题、不提前展开模型 |
| 二、问题分析 | 1.2—1.6 | 四问机制＋一张总图 |
| 三、模型假设 | 0.5—0.8 | 只写必要假设并给理由 |
| 四、符号说明 | 0.7—1.0 | 核心全局符号，不求大全 |
| 5.1统一基础 | 1.5—2.0 | 数据时间轴、能量平衡、SOC、互斥 |
| 5.2问题一 | 2.5—3.0 | 完整基线＋LP下界 |
| 5.3问题二 | 3.5—4.0 | 两阶段信息顺序＋全年结果 |
| 5.4问题三 | 4.5—5.5 | 滚动更新与逐次结算是重点 |
| 5.5问题四 | 3.5—4.5 | 因果策略＋完全信息下界 |
| 六、模型检验 | 2.0—2.8 | 物理、费用、因果、基线四类验证 |
| 七、评价推广 | 0.8—1.2 | 整体评价，不逐问重复 |
| AI声明＋参考文献 | 1.0—1.5 | 位于正文末且计入30页 |
| 正文合计 | 约24—27页 | 最大不超过30页，预留3页余量 |

当版面超限时，删减顺序应为：装饰图、重复问题重述、重复公式、次要中间表、无结论价值的算法介绍；不得优先删去模型由来、关键约束、核心定量结果和验证证据。大篇幅日级明细、全部代码、参数全表和次要图进入附录或支撑材料。

## 七、第一版论文的完成门槛

第一版不能只是“章节齐全”的文字壳。进入排版前至少应满足：每问都有题目事实到模型结构的完整解释；每个目标函数和约束都能指出题目来源；每个摘要数字能追溯到结果表；所有图表都有明确的声明用途；四问的单位、SOC口径、效率口径和结算口径一致；Q2与Q4不存在未来数据泄漏；Q3调整相对上一版有效计划结算；论文不出现尚未通过保留门槛的CVaR模块；参考文献只收录正文实际引用且经核实的条目；AI声明与真实使用台账一致。

完成DOCX/PDF后必须逐页渲染检查，重点查看中文字体替换、公式上下标、表格跨页、图题断页、页码、摘要是否溢出以及正文是否超过30页。标准模板的字号和边距是排版基线，不能通过缩小字体、压缩页边距或删除必要解释来“挤过”门禁。
