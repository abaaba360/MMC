# 2026国赛标准论文Word模板格式规范

> 本规范由《2026数学建模国赛标准论文Word模板.doc》提取整理，是可执行的排版基线，不是官方文件的替代品。
> 规则优先级：当年官方通知/章程 > 官方模板与官方评阅解读 > 本规范 > 往届论文习惯。

---

## 0. 总体规则（最高优先级）

| 项目 | 要求 |
|------|------|
| 纸张 | A4 |
| 页边距 | 上下左右 ≥ 2.5cm |
| **目录** | **禁止目录**（"论文不要目录"） |
| 正文页数 | **≤ 30 页**；口径含正文主体、AI工具使用声明和参考文献，不含摘要专用页和附录 |
| 附录 | 页数不限 |
| 身份信息 | 不得出现参赛者身份和学校信息 |
| 公式 | 一律用公式编辑器（Word公式编辑器/LaTeX），**严禁截图** |

---

## 1. 论文题目

**格式**：基于XXX模型/方法/理论的XXX问题研究

示例：`基于机理-数据混合建模与多目标优化的芯片微通道散热系统研究`

---

## 2. 摘要（最重要，严格1页内）

**三段式结构（虎头-猪肚-豹尾）**：

| 段 | 名称 | 内容 | 要点 |
|----|------|------|------|
| 第1段 | **虎头** | 背景+问题 | 简述题目背景、现存问题、研究意义，明确本文要解决的所有问题 |
| 第2段 | **猪肚** | 方法+结果 | 按问题顺序介绍建模思路、数据处理、模型方法、求解过程和**量化结果**，重点突出方法与结果 |
| 第3段 | **豹尾** | 创新+价值 | 总结模型优势、创新点、精度/稳定性/鲁棒性，或应用价值/推广意义 |

**硬约束**：
- 电子论文第一页为摘要专用页，只含论文题目、摘要和关键词，无需英文翻译
- 原则上**不超过一页**，以最终PDF/Word渲染结果为硬门禁；字数只作版面调节指标，不设300–500字伪硬约束
- 关键词数量以表达完整和版面为准，优先写研究对象、核心模型或关键机制

---

## 3. 一、问题重述

- 用自己的话对问题重新总结，**关键在改写**（严禁照抄原题）
- 半页到一页左右
- 列出必要数据、要解决的问题、研究对象关键信息
- ⚠️ 该部分是**查重最容易出问题的部分**，务必改写

---

## 4. 二、问题分析

- **每个问题单独分析一小节**（1.1 问题一的分析、1.2 问题二的分析…）
- 每节内容：题目信息与条件 → 整体分析 → 确定用什么方法建模；分析过程简明扼要，**不需要放结论**
- 每节约10行左右
- 仅当流程图能比文字更清楚地呈现跨问依赖或推理链时使用；不得为了凑形式加入模板化流程图

---

## 5. 三、模型假设

逐条列出（itemize/编号），每条含假设理由。常见假设类型：

1. **平稳性假设**：研究周期内无重大政策调整、突发灾害等强外部冲击，运行规律保持稳定（保障时序类模型有效）
2. **简化假设**：不考虑XX次要成本/因素波动，仅围绕核心传导关系分析（剥离次要变量）
3. **真实性假设**：XX主要由XX两类核心因素决定（符合客观现实）
4. **合理性假设**：XX具备理性行为特征，小幅变化不会造成大规模流失（符合常规规律）
5. **参数假设**：样本中异常值仅由随机统计误差产生，不存在系统性偏差（保证预处理可靠）

> 每条假设格式：`假设N（名称）：内容。理由：...`

---

## 6. 四、符号说明

- **三线表**格式，列：`符号 | 含义 | 单位`
- 只写主要全局变量，**临时变量不写**
- 符号遵循领域惯例并保持唯一、一致、可读；不为追求形式强行改用希腊字母
- 即使在符号说明里解释了，**下文首次出现时仍要说明**

---

## 7. 五、模型建立与求解（核心章节，占正文60-70%）

**建模原则**：
1. 模型基本正确、简明、便于求解
2. 建立模型要有根据，能详细阐述建模逻辑
3. 模型实用有效，以能有效解决问题为原则
4. 模型具有可解性（考虑到下一步求解）
5. 不追求数学上的难度，不超出本科数学知识

**建议的完整论证要素**（可按题目逻辑合并或调整标题，不机械套五段）：

| 子节 | 内容 |
|------|------|
| 5.X.1 | **数据与输入处理**：仅在确有处理时说明步骤及其必要性 |
| 5.X.2 | **XXX模型的建立**：公式推导、变量说明 |
| 5.X.3 | **XXX模型的求解**：算法/求解步骤，配图 |
| 5.X.4 | **XXX模型的检验** |
| 5.X.5 | **XXX结果的分析** |

> 公式务必用公式编辑器（LaTeX `equation` 环境 / Word公式编辑器），**严禁截图**。

---

## 8. 六、模型检验

检验必须针对模型最可能失败的环节设计，不机械凑“误差/灵敏度/稳健性三件套”。下表是按题型选用的工具箱：

| 检验类型 | 适用题型 | 内容 | 量化标准 |
|----------|---------|------|---------|
| **误差分析** | 预测/拟合/机理题**必写** | RMSE、MAPE 量化精度 | 如"RMSE=3.26、MAPE=4.12%，相较传统模型大幅降低" |
| **灵敏度分析** | 优化/评价/多参数模型 | 核心参数 ±10%、±20% 梯度扰动测试 | 参数小幅波动时结果偏差控制在5%以内，方案无明显偏移 |
| **稳健性检验** | 结论依赖噪声、样本或算法时 | 重采样、噪声、边界情景或替代求解器 | 报告结论稳定范围及失效边界 |

---

## 9. 七、模型优缺点评价

**原则：优点说充分，缺点不回避。**

| 子节 | 内容 | 要求 |
|------|------|------|
| 7.1 模型的优点 | 优点表述形式 | 简洁实用效率高 / 创新性强 / 结果准确精度高 / 考虑全面实用性强 / 经各类检验稳定性高 |
| 7.2 模型的缺点 | 缺点表述形式 | 受XX因素限制未考虑XX / 因素理想降低普适性 / 模型复杂计算时间长 |
| 7.3 模型的改进 | 针对缺点提思路 | 提出改进思路即可，具体可操作 |

## 10. AI工具使用声明与参考文献

AI工具使用声明采用2026官方二选一文本，置于参考文献之前：

- 未使用：`本参赛队在竞赛过程中未使用任何AI工具。`
- 已使用：`本参赛队在竞赛过程中使用了AI工具，主要用于〖简要用途，如语言润色、代码调试等〗，详细使用情况见支撑材料。`

使用AI时，支撑材料内须含准确命名为 `AI工具使用详情.pdf` 的报告，记录工具及版本、使用阶段和目的、主要提示方式与过程、采纳/人工修改/核验情况（语言润色除外）。2026规定不再沿用2025版“正文逐处标注并把AI工具列入参考文献”的表述；如后续官方更新则从其新规。

参考文献采用题目和官方模板要求的著录格式：

**文献类型标注**：

| 类型 | 格式 |
|------|------|
| 著作 | 作者姓名. 题名[M]. 出版地: 出版社, 出版年. |
| 期刊论文 | 作者姓名. 题名[J]. 期刊名称, 年, 卷(期): 页码. |
| 会议论文集 | 作者姓名. 题名[C]//论文集名称, 会议地点, 会议日期. |
| 学位论文 | 作者姓名. 题名[D]. 出版地: 出版者, 出版年. |
| 专利 | 专利申请者. 专利题名: 专利国别, 专利号[P]. 公告日期或公开日期. |
| 电子文献 | 作者姓名. 题名[EB/OL]. 出版地: 出版者, 出版年(更新日期). 获取路径. |
| 报告 | 作者姓名. 题名[R]. 出版地: 出版者, 出版年. |
| 标准 | 标准号. 题名[S]. 出版地: 出版者, 出版年. |

参考文献数量由实际引用决定；正文必须引用，无引用条目删除。

## 11. 附录

| 内容 | 说明 |
|------|------|
| **附件的文件列表** | 介绍附件有哪些文件 |
| **源代码** | 论文附录列出全部可运行代码；同一份代码还必须进入支撑材料包，并说明语言、作用、输入输出 |
| 详细证明或求解过程 | 某一问题的详细推导 |
| 网上的数据 | 自行搜集的补充数据 |
| 较大的流程图 | 放不下的完整流程图 |
| 繁杂的图表/计算结果 | 大篇幅中间结果 |

## 12. 与现有模板的关系

- 本规范对应 Word 标准模板；若用 LaTeX 输出，章节结构与之一一对应
- 五、模型建立与求解的 5.X.1~5.X.5 结构，对应 MriteThesis 模板的 分析与准备/建模与求解 拆分思路（可合并或拆分，但**必须覆盖五段内容**）
- 模型检验三件套（误差/灵敏度/稳健性）优先采用 Word 模板的量化表述
