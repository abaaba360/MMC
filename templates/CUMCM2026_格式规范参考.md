# 2026年全国大学生数学建模竞赛论文格式规范（参考摘要）

> **来源**: 全国大学生数学建模竞赛组委会 2026年修订稿（2026年7月2日发布）
> **官方公告**: http://dxs.moe.gov.cn/zx/a/hd_sxjm_gsyw/260702/2046411.shtml
> **竞赛官网**: http://www.mcm.edu.cn | https://www.cmathc.org.cn

---

## 一、纸质版论文要求

### 纸张与装订
- 白色A4纸打印（单面/双面均可）
- 上下左右各留出**至少2.5厘米**页边距
- 从左侧装订

### 页面顺序
| 页码 | 内容 | 说明 |
|------|------|------|
| 第1页 | **承诺书** | 需全体队员亲笔签名 |
| 第2页 | **编号专用页** | 赛区统一编号 |
| 第3页 | **摘要专用页** | 含标题和关键词，无需英文翻译，原则上不超过一页 |
| 第4页起 | **正文** | 不要目录！不超过30页 |
| 正文之后 | **论文附录** | 页数不限，必须打印并与正文装订 |

### 页码
- 从摘要页（第3页）开始用阿拉伯数字从"1"连续编号
- 页码位于页脚中部

### 附录内容（必须包含）
- 支撑材料文件列表
- 建模所用到的**全部完整可运行的源程序代码**（含EXCEL、SPSS等）
- 确实没有使用程序的，需在附录中明确说明"本问题/本论文未使用程序"

> ⚠️ **严重警告**：缺少必要的源程序或程序无法运行，可能被取消评奖资格！

### 匿名要求
- 摘要页、正文和附录中**任何地方**不能显示参赛者身份和所在学校及赛区信息

### 参考文献
- 所有引用他人或公开资料的成果必须按科技论文规范列出参考文献
- 并在正文引用处标注

### 字号字体
- 不做统一要求，各赛区可在不违反规范前提下自行要求
- 业界惯例：正文宋体小四(12pt)，标题黑体，英文Times New Roman

---

## 二、电子版论文要求

- 内容及格式必须与纸质版**完全一致**（包括附录）
- 单独文件，格式为**PDF或Word**（建议PDF）
- 大小**不超过20MB**
- **不要压缩**，电子版第一页须为摘要专用页
- **承诺书和编号专用页不要放入电子版**

---

## 三、支撑材料要求

- 使用WinRAR压缩为一个文件（RAR或ZIP格式）
- 大小**不超过20MB**
- 包含内容：
  - 所有可运行源程序
  - 自主查阅的数据资料
  - 大篇幅中间结果图表
- **所有文件中不能有显示参赛者身份的信息**
- **不能包含承诺书和编号专用页**

## 四、AI工具使用规定（2025试行版，2026需关注更新）

> **官方公告**: https://dxs.moe.gov.cn/zx/a/hd_sxjm_gsyw/250904/2017973.shtml

### 核心要求
1. **公开透明**：可使用AI工具，但核心建模与分析须由参赛队独立完成
2. **正文标注**：AI生成内容应在正文对应位置标注，并在参考文献中列出
3. **参考文献格式**：`[编号] 工具名称，版本/型号，开发机构，使用日期`
4. **支撑材料**：须包含PDF格式的《AI工具使用详情》，含：
   - 工具名称和版本
   - 具体使用目的和环节
   - 关键交互记录（提示词与回复）
   - 采纳和人工修改情况
5. **违规处理**：不符合要求 → 取消评奖资格
6. **未使用AI**：须在参考文献之后声明"本参赛队未使用任何AI工具"

## 五、评审标准（社区整理，非官方发布）

| 维度 | 权重 | 关键要点 |
|------|------|---------|
| 模型质量 | 50-60% | 假设合理性与必要性、逻辑自洽、方法创新性 |
| 问题解决能力 | 30-40% | 赛题针对性、算法效率、结果正确性 |
| 论文规范性 | 10-20% | 摘要凝练性、图表专业性、参考文献规范 |
| 验证与灵敏度 | 5-10% | 稳健性检验、多模型对比、参数敏感性分析 |

### 加分项
- 跨学科方法创新融合
- 结合国家战略提出量化建议（双碳、乡村振兴等）
- 确有突出创新点可"瑕不掩瑜"

### 不鼓励
- 非针对具体问题的数学方法堆积
- 通用模型和算法的简单拷贝
- "套路化"、"形式化"、"虚拟化"的表面文章

## 六、论文结构模板

```
承诺书（纸质版第1页，电子版不含）
编号专用页（纸质版第2页，电子版不含）
摘要（第3页/电子版第1页，300-500字，含关键词）
一、问题重述
二、问题分析
三、模型假设
四、符号说明（三线表）
五、模型的建立与求解
    5.1 问题一
    5.2 问题二
    ...
六、模型的检验与分析
七、模型的评价与推广
八、参考文献（GB/T 7714-2015）
AI使用声明（2026年新增）
附录（全部源代码）
```

## 七、模板使用说明

### LaTeX模板（推荐）
```bash
# 模板位置: templates/CUMCMThesis/
# 编译
xelatex example.tex
xelatex example.tex  # 跑两遍解决交叉引用

# 纸质版（含承诺书和编号页）
\documentclass{cumcmthesis}

# 电子版提交（去掉封面）
\documentclass[withoutpreface,bwprint]{cumcmthesis}
```

关键配置：
```latex
\tihao{A}              % 选题号
\baominghao{4321}      % 报名号
\schoolname{XX大学}    % 学校名称
\membera{ }            % 队员1
\memberb{ }            % 队员2
\memberc{ }            % 队员3
\supervisor{ }         % 指导教师
\yearinput{2026}
\monthinput{9}
\dayinput{10}
```
