## 一、题目总体方向

数学建模论文智能评估系统与多智能体优化方法。类型：**文本分析 + 评价建模 + 小样本预测 + 优化策略**的复合题目（Q1→Q2→Q3 强依赖）。

- 核心任务：对43篇参赛论文PDF提取可量化文本特征，建立质量评分体系，识别关键特征，设计优化策略。
- 数据规模：附件1（30篇混合题型）、附件2（10篇同一赛题"数字胜任力增值评价"）、附件3（3篇康养A题中等质量）。
- 关键约束：**公式是Unicode符号内嵌（非LaTeX）**、**2篇扫描版无文本层（剔除）**、**小样本（Q2仅9篇）**、**AI痕迹无真值标签**。

## 二、各题求解思路

### 问题一：质量综合评价指标体系与评分分级

**输入**：附件1的30篇论文文本（去扫描版29篇）
**输出**：6一级维度+21二级指标、组合权重、百分制得分、5级分级（优秀/良好/中等/及格/不及格）
**核心**：一级维度AHP主观权重（对齐国赛：D1模型方法0.30/D2公式推导0.15/D3问题解决0.25/D4逻辑0.10/D5验证0.08/D6规范0.12，CR<0.1）+ 二级指标熵权客观权重 + 乘法合成组合赋权 + 线性加权评分
**关键点**：
- 21个二级指标全部可自动计算（密度化，除以千字）
- 逻辑连接词密度X41为**适中型**指标（最优区间由29篇P25-P75标定）
- 公式密度用Unicode符号正则（𝜆𝜉𝜃𝜇𝜎∑∫√等），禁止LaTeX统计

**建模**：
- 主方法：层次指标体系 + AHP/熵权组合赋权 + 线性加权 + 阈值分级（90/80/70/60）
- 分级合理性：K-means(k=5)+Jenks对照，报告ARI一致性
- 权重合理性：CR<0.1 + 权重±10%扰动敏感性（≥85%等级不变）

### 问题二：质量与文本特征关联 + 预测模型

**输入**：附件2的10篇（去扫描版9篇）+ Q1评分作真值
**输出**：特征-质量关联、关键特征清单、质量调整因子k、预测模型、小样本稳定性
**核心**：以Q1评分y为真值，特征筛选（Spearman|ρ|≥0.3→VIF<10→LASSO保留2~4关键特征），Ridge/LASSO正则化预测，质量调整因子k显式嵌入
**关键点**：
- 小样本9篇，用LOOCV（非K折）选λ
- 稳定性三重：LOOCV误差 + Bootstrap(1000次)系数CI + 删一法参数漂移
- 关键特征三法交叉：LASSO系数路径 + PLS VIP + 随机森林置换重要性

**建模**：
- 主方法：Ridge/LASSO正则化线性模型 + 质量调整因子k=ȳ/ŷ̄
- 质量调整因子双形式：加法型β_0（截距）+ 乘法型k（比例校正）
- 备选：OLS基线（出相关系数表）、PLS、树集成对照

### 问题三：优化策略（AI痕迹检测 + 逻辑断层识别）

**输入**：附件3的3篇中等论文 + Q1评分 + Q2关键特征
**输出**：AI辅助程度评估、逻辑断层定位、修改方案、优化后得分预测
**核心**：8类AI痕迹特征（句长CV、n-gram重复、AI高频词、词汇熵、逻辑词异常、标点熵、段落模板化、公式-代码一致性）→ 以29篇人类分布z标准化 → 三种离群（3σ/马氏距离/Isolation Forest）聚合 → AIscore∈[0,1]
**关键点**：
- 无真值标签 → 无监督离群检测，明确声明"统计代理"
- AI辅助程度分级：低<0.33/中0.33-0.66/高>0.66
- 逻辑断层5类规则引擎，输出命中位置（第几段/第几章）
- 优化方案：对低分维度二级指标（<人类P25）生成可操作提升清单，代入Q2反推得分

**建模**：
- 主方法：无监督离群检测（Isolation Forest+3σ+马氏距离）+ 规则引擎逻辑断层 + 特征级优化 + Q2反推得分
- 备选：专家系统（规则思路已并入）、序列标注（无标签不可行，淘汰）

## 六、异常预案

- 扫描版OCR失败 → 直接剔除（已决策），论文披露
- 小样本LASSO不稳定 → 增大Bootstrap次数、降特征维度、报告删一法漂移
- 熵权法ln0 → ε平滑(x+1e-6)
- AHP不一致 → 调整判断矩阵或改用模糊AHP
- AI痕迹离群过度 → 声明统计代理，用多离群方法互证
- 中文分词问题 → jieba不可用则退化为字符n-gram
- Unicode公式正则漏检 → 扩充符号表（数学字母区U+1D400-U+1D7FF）
