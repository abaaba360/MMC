## 一、题目总体方向

高性能芯片歧管式微通道热管理系统优化问题。类型：**机理建模 + 小样本代理建模 + 多目标优化 + 鲁棒设计 + 敏感性分析**的递进问题链（Q1→Q5 强依赖）。

- 核心任务：由 84 个 CFD 仿真样本建立 (r,h,n)→(R,P,T) 的映射（机理+数据代理），求解综合最优设计与鲁棒设计方案，并评估扰动敏感性。
- 数据规模：附件2 84行×7列，**结构化全因子网格**（4基线 r=0,n=0 + 80有针肋 r>0×n∈{2,4,6,8,10}×h∈{3,3.5,4,4.5}），n 仅偶数。
- 研究递进：Q1 机理(解释规律) → Q2 代理(精确映射) → Q3 多目标最优 → Q4 鲁棒 → Q5 稳健验证。

## 二、各题求解思路

### 问题一：机理建模与影响规律分析

**具体分析**：
- 输入：附件1物性/工况 + 附件2 84样本
- 输出：流向分段热-流耦合机理模型 f(r,h,n)→(R,P,T)、影响规律曲线、三指标合理性论证
- 核心难点：n 增大 T 先降后升的 U 型（横向混合 vs 沿程温升竞争）；R-r 的 U 型
- 定位：为 Q2 提供物理先验结构，为 Q3 提供可行域

**建模**：
- 主方法：1D 流向分段温度剖面机理模型 + 无量纲分析（Dittus-Boelter/层流关联式）
- 标定：修正系数 κ 用 84 样本最小二乘标定（机理-数据联合）
- 备选：集总电阻网络（基线）、幂律回归（影响规律定量化）

### 问题二：代理模型构建与评估

**具体分析**：
- 输入：附件2 84样本
- 输出：GPR 代理 f(r,h,n)→(R,P,T)，5折CV + LOOCV 双校验，与多项式/树基线对比
- 核心难点：84 小样本防过拟合；R 量程仅 7%（用 RRMSE 相对误差）

**建模**：
- 主方法：GaussianProcessRegressor，Matern(5/2) ARD 核 + WhiteKernel，输入标准化、目标 min-max 归一化
- 输出 σ²(x) 预测方差 → 供 Q5 认知不确定度
- 备选：多项式二次(Ridge)、随机森林

### 问题三：多目标优化与综合最优设计

**具体分析**：
- 输入：Q2 代理模型
- 输出：Pareto 前沿、(r*,h*,n*) 综合最优方案
- 核心难点：3 目标量纲不同（min-max 归一化）；n 整数 + 可行域耦合约束(r=0⟺n=0)

**建模**：
- 主方法：NSGA-II（混合整数：n 连续松弛→就近取整→代理复算校正），min-max 归一化目标
- 综合决策：TOPSIS + 熵权/等权重双验证，ε-约束法独立复核前沿
- 备选：加权标量化+差分进化

### 问题四：权重敏感性与鲁棒设计方案

**具体分析**：
- 输入：Q3 框架
- 输出：权重→方案映射、Max-Min 鲁棒方案、判定依据
- 核心难点：双层 max-min 不可解 → 顶点闭式约简

**建模**：
- 主方法：max_{w∈Δ³} S(x,w) = max{R̃,P̃,T̃}（线性函数顶点性质）→ 单层 minimax"最劣势指标最小化"
- 场景权重箱跨场景鲁棒（枚举箱顶点）
- 备选：权重单纯形网格扫描（敏感性可视化）、均值-方差风险调整

### 问题五：加工误差与工况波动的敏感性/稳定性分析

**具体分析**：
- 输入：Q2 代理 + Q3/Q4 方案
- 输出：扰动→性能响应、敏感性排序、稳定性评估（P10/P50/P90、失效概率、CV）

**建模**：
- 主方法：双源不确定度蒙特卡洛（参数偶然：加工误差截断正态±5%、n取整±1 + GPR认知 σ²(x) + 工况流量±10%）
- 备选：局部弹性灵敏度（主效应排序）、Sobol 全局灵敏度

## 六、异常预案

- 数据异常：附件2 列名乱码/类型错 → data_loader 强制转换，84 样本断言
- 代理异常：GPR 不收敛 → 核超参 bounds 放宽 / n_restarts 增加；过拟合 → WhiteKernel 噪声
- 优化异常：NSGA-II 不收敛 → 增大代数/种群；整数约束 → 取整后代理复算校正（禁直接四舍五入）
- 结果异常：与数据矛盾 → 回溯数据清洗与模型环节
- scipy 求解器：minimize 只做最小化（最大化取负）；不等式约束方向 fun(x)>=0；不信任 success 标志，解后重验约束
